# GardenOS Prototypes

This repository contains multiple prototypes developed as part of the GardenOS project.

- The **final expert system** can be found at  
  `GartenOSExpert/GardenOS_expert.html`

- The **current mobile application** is located in  
  `GartenOSMobile_2.0`  
  Please refer to the `README.md` inside this folder for instructions on how to install and run the app.

- The folder `GardenOSMobile` contains an **earlier prototype version** of the mobile application and is included for documentation purposes only.
